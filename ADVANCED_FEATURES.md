### 2. **Scout Agent** (`/scout-agent`) 🎯
**Automated Property Hunting with Custom Criteria**

**Elite Feature:** Requires "Mentee Elite" or Admin role

**What it does:**
- Creates customized AI agents that search for properties matching YOUR exact criteria
- Runs 24/7 in the background
- Sends notifications when matching properties are found

**Custom Criteria:**
- Target counties (e.g., "Travis, Harris, Dallas")
- Property type (SFR, Commercial, Land)
- Minimum bedrooms/bathrooms
- **Opportunity Score threshold** (AI-calculated viability score 0-100)
- Notification method (Email or SMS)

**Workflow:**
1. Create a named agent (e.g., "Texas SFR Hunter")
2. Set criteria (min score: 70, counties: Travis, Harris)
3. Agent runs automatically
4. Get notified when properties match
5. View recent finds directly in the agent card

**Real-time Features:**
- Live property matching
- Recent finds preview (top 3 matches)
- Toggle agents on/off
- Edit criteria anytime
